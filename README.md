# Kassabuch

Offline-App für gemeinsame Ausgaben (Ersatz für Splid): Suche, Datum, Kategorien, Saldo zwischen Personen, Auswertung und Scan des QR-Codes auf österreichischen Kassenbelegen (RKSV).

Die App läuft komplett im Browser. Alle Daten bleiben auf dem Handy (Browser-Speicher) – in diesem Repository liegen nur die App-Dateien.

**App öffnen:** https://shetzenauer.github.io/kassabuch/ → in Chrome ⋮ → „App installieren“.
